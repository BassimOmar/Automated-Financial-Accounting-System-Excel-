# Automated Financial Accounting System (Excel)

Developed an automated financial accounting system in Microsoft Excel to simulate a real-world accounting workflow. The workbook records journal entries, classifies transactions using a Chart of Accounts, automatically updates the General Ledger, generates a Trial Balance, and produces dynamic Income Statement and Balance Sheet reports.

The project applies core accounting principles while leveraging Excel formulas to reduce manual work and improve accuracy. Functions such as **XLOOKUP**, **SUM**, **SUMIF**, **IF**, and **OR** were used to automate account lookups, transaction validation, balance calculations, and financial reporting.

### Key Features

* Automated Chart of Accounts management
* Journal Entry recording and validation
* Dynamic General Ledger generation
* Automatic Trial Balance calculation
* Automated Income Statement and Balance Sheet
* Cross-sheet data integration and formula-driven reporting
* Error reduction through automated calculations
